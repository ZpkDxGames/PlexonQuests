# PlexonQuests 4.0.0-rc.1 — Phase 2 Premium Journal

This is a **prerelease** candidate. Stable `v4.0.0` remains blocked until PlexonCraft runtime certification passes.

## Phase 2 additions

- Premium quest journal: Overview, Active, Available, Categories, Tracked, Completed/History, Statistics, and Help.
- Derived journal states: LOCKED, AVAILABLE, ACTIVE, TRACKED, COMPLETABLE, COMPLETED, COOLDOWN, EXPIRED, DISABLED.
- Completion-based quest prerequisites with dependency graph validation.
- Bounded asynchronous completion-history cache for prerequisite resolution.
- Tracked terminology layered over the compatible 3.x pinned assignment contract.
- Additive immutable `PlexonQuestsJournalAPI` and `QuestTrackEvent`.
- Placeholder aliases for tracked quest and active/completed counts.
- Expiring actor/action/target-bound confirmation for destructive admin commands.
- Phase 2 migration, API, recovery, and runtime-certification documentation.

## Preserved mature runtime

The 3.3.1 indexed objective engine, PlexonCore Runtime single-authority block acquisition/provenance, SQLite WAL persistence, deterministic rotations, exact ItemStack rewards, and guarded claim transaction architecture remain authoritative.

## Distribution

Release assets include:

- `PlexonQuests-4.0.0-rc.1.jar`
- `SHA256SUMS.txt`

The tag workflow rebuilds and tests the exact tagged SHA with Java 25, provisions the pinned PlexonCore 2.0.4 API, verifies SQLite packaging, rejects shaded PlexonCore/PlaceholderAPI runtime classes, and generates/verifies the SHA-256 file before publication.

## Stable gate

Do **not** merge/promote based on CI alone. PlexonCraft must still certify representative 3.3.1 migration, the journal flow, every supported objective/provenance path, rewards and duplicate-claim rejection, full-inventory behavior, rotations/reset edges, admin confirmations, restart/reload persistence, PlaceholderAPI, cross-plugin integrations, Spark/MSPT comparison, and a >=30-minute soak with zero HIGH/CRITICAL defects.
