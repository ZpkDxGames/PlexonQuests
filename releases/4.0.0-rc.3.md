# PlexonQuests 4.0.0-rc.3

Phase 3 final premium Quest Journal UX candidate.

## Player-facing UX

- Aligns substantial 54-slot journal screens with the shared Plexon control geometry: Back/Home at 45, Previous at 48, page/context at 49, Next at 50, and the primary contextual action at 53.
- Reserves slot 4 for clear section identity while retaining direct Journal Home, Active, Eligible, Completed, Tracked, and Help navigation.
- Keeps state, scope, category, objective, prerequisite, reward, completion, and locked-state language player-facing.
- Adds bounded rapid-click debounce to journal actions.
- Updates Track/Untrack presentation in place instead of reopening the inventory solely to refresh it.
- Retains actionable empty states and asynchronous Completed history rendering without reopen flicker.

## Preserved Phase 3 architecture

This candidate does not redesign quest progression, persistence, prerequisites, pools, reward transactions, PlexonCore event routing, provenance/origin handling, or accepted Phase 3 performance behavior. Claim, tracking, reroll, history, and state authority remain delegated to the existing services.

## Release gate

- Java 25 / Paper 26.2 candidate.
- Canonical CI and packaged distribution verification are required for the exact source candidate.
- This is an immutable prerelease candidate, not a stable promotion.
- Runtime certification remains pending and must be performed by Phase 3 Runtime / Soak / Stable Gate on this exact RC artifact before stable promotion can be recommended.
